## Локальный запуск

**Предварительные требования:** [Android Studio](https://android.com)

1. Откройте Android Studio
2. Выберите **Open** (Открыть) и укажите директорию, содержащую этот проект
3. **КРИТИЧЕСКИ ВАЖНО:** Найдите файл `App.zip` в корневой директории. Разархивируйте его и поместите все извлеченные файлы напрямую в папку проекта вместе с остальными файлами. Полный исходный код не удалось загрузить напрямую из-за ограничений GitHub на размер файлов.
4. Позвольте Android Studio исправить любые несовместимости при импорте проекта.
5. Создайте файл с именем `.env` в директории проекта и укажите в нем `GEMINI_API_KEY` со своим ключом API Gemini (пример настройки смотрите в `.env.example`)
6. Удалите эту строку из файла `build.gradle.kts` приложения: `signingConfig = signingConfigs.getByName("debugConfig")`
7. Запустите приложение на эмуляторе или физическом устройстве
8. Это приложение работает как специализированный игровой цикл симулятора в стиле «мусор-дроп» (сбор выпадающих предметов), обрабатывая физику в реальном времени и создание объектов, привязанных к контекстным триггерам API Gemini.
